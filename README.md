# Abisha & Rohit Wedding Website

A clean-from-scratch wedding website matching the cream / gold / brown luxury theme from the previous design.

## Files
- `index.html` — structure and content
- `css/style.css` — all styling and responsive layout
- `js/script.js` — countdown, mobile menu, invitation modal, music, active navigation
- `assets/logo.png` — cropped A&R logo
- `assets/invitation.png` — invitation spread
- `assets/couple.png` — couple image

## Important
Replace `assets/canthelp.mp3` with your actual music file, or change the audio source in `index.html`.

Open `index.html` with Live Server in VS Code.
